1. Project Name : DevStack

2. description : Dev Stack is a responsive web application where developers can explore different technologies and add their favorite technologies to their development stack.

3.Technologies Used : react,Tailwind CSS,typescript,React-Toastify (NPM Package),JSON (for technology data),Vite (build tool)

4.Features : (1): Browse different development technologies
(2) : Add technologies to personal stack
(3) : Remove technologies and clear the stack

####### react question answer#########

1. JSX helps to write HTML-like code inside JavaScript and It makes React UI code easier to read and write.

2.Props pass data from a parent to a child and State stores data that can change inside a component.

3.useState is used to create and manage state I used it to store the selected technologies in the stack.

4.useEffect is used to handle side effects and i can useEffect hook in this project to fetch json data.

5. key helps React identify each item in a list.

6.Conditional rendering means showing UI based on a condition.

example: I used it to show "Your stack is empty" when no technology is selected.

7.A parent passes data using props and A child can send data back by using a function.
